## 🎮 About

**ZClient** is a custom Minecraft client focused on giving players a clean, customizable, and optimized experience while keeping the project lightweight.

Built for **Minecraft 26.2** with Fabric.

## ✨ Features

- ⚡ Performance-focused client design
- 🎨 Customizable HUD
- 🖱️ Custom client UI and controls
- 🧩 Fabric-based mod architecture
- 🔧 Client-side customization and utilities
- 🚀 Lightweight approach to extra features

> ZClient is actively developed. Features may change as development continues.
